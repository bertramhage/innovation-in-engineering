# Fire detection model
A simple ML decision tree to detect fire using a DHT22 sensor.

## Setup and Usage

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/bertramhage/innovation-in-engineering.git
   cd innovation-in-engineering
   ```

2. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On macOS/Linux
   # or
   # venv\Scripts\activate  # On Windows
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Set the API key as an environment variable:
   ```bash
   export API_KEY="your_thingspeak_api_key"  # On macOS/Linux
   # or
   # set API_KEY=your_thingspeak_api_key  # On Windows CMD
   ```

### Running the Application

Run the fire detection system with the default threshold (0.5):
```bash
python main.py
```

Or specify a custom threshold:
```bash
python main.py --threshold 0.7
```

The system will continuously monitor sensor data and alert you when it detects a fire.

## Synthetic data generation
Model is trained on synthetic data generated by the `data/syn_data.py` script.

To train the model again run
```bash
python pipeline.py --data_path [DATA PATH]
```
